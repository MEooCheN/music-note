关于本站

这是一份个人学习笔记，不是教程。

作者在学这些东西，边学边记。所以站内文字有草稿性质，不保证正确。 请以原教材、原谱和原始数据集为准。

一、内容可信到什么程度

站内内容分三档，可靠性差别很大，混在一起看会出事，所以分开列：

类别可靠性
对位硬规则判定 机器可验。21 条规则逐条可查、可改、可关。 在项目里跑 node tools\verify.js 与 node tools\check-rules.js，结果就是结论。
DCML 和声标签语法 官方正则。取自 DCMLab/standards v2.3.0，是原样使用，不是近似实现。
讲解文字、文献分析结论 草稿。可能有错，包括事实性错误。这一档占页面的绝大多数。

还有三条边界必须说清

  • 规则合规 ≠ 音乐好听。检查器是筛子，不是裁判。真实文献是范本，耳朵是最终裁判。
  • 规则集来自通行教学共识，不是逐字引用某本教材。 不同教材在细节上（尤其反向五八度、连续三六度的上限）并不一致， 所以规则做成了可切换的。
  • 风格归属不保证。16 世纪实际写法与教科书规范有出入——检查器实现的是教科书规范。

二、内容与谱例从哪来

站内的谱面一律用 Fux 本人的对位练习，不用程序生成的，也不用作者手写的。

  • 谱例来源：github.com/MarkGotham/species ——Fux《Gradus ad Parnassum》全部对位练习连同 Fux 本人的解答。
  • 每条进站的谱例都过两道关：固定旋律与 Fux 为该调式规定的旋律逐音吻合， 且 Fux 的解答喂进本站检查器必须 0 错误。
  • 这个流程抓出过检查器自身的若干错误。相关记录在仓库的 docs/检查器交接文档.md 里。

谱面与音频由 MuseScore Studio 导出；网站本身不渲染乐谱，只显示导出的结果。

五、已知限制

  • 谱面与音频需要在 http 下打开。浏览器不允许 file:// 页面读取 同目录的 SVG，所以在本地双击 index.html 时谱面区会显示一句说明。 在项目目录里跑一条静态服务即可（python -m http.server 8000）。
  • 真实文献的谱面要自己准备。站内只给权威谱面的链接，不转载谱面本身。
  • DCML 官方工具链未使用。官方的 ms3 解析工具需要 Python 包， 本站的标签检查器改走 MusicXML + 标准库解析这条路。
  • 三声部对位只查一部分。目前只查三对声部之间的平行五/八度与声部交错； 音型层面（经过音／辅助音／cambiata／挂留／终止式）尚未实现。
  • 有一条规则没有反例。检查器的 H04（反向到达五度/八度）目前构造不出能单独 证明它的例子，所以它是未经检验的，不是"检验通过"。
  • 进度存在你自己的浏览器里（localStorage），不上传、不跨设备同步。 清除浏览器数据会一并清掉。

六、技术上的诚实交代

本站没有服务器、没有数据库、没有第三方依赖，全部是静态文件。 对位练习的批改是在你的浏览器里当场跑规则检查器完成的， 所以它和仓库里的规则集永远一致——改规则，练习的判定自动跟着变。

这个仓库自带一整套检查闸门（内容标准、规则覆盖、页面加载顺序、音画对齐等）， 每次改动都会跑一遍。但它们只能保证"没有已知的错"，不能保证内容是对的。
