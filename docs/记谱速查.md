# 记谱速查

本站在两处用到这种文字记谱：**规则检查器**（`tools/verify.js`）和**练习数据**。
它只表达音高与时值，不负责排版——排版全部交给 MuseScore。

## 音名

```
音名        C  D  E  F  G  A  B      （大小写都行，b 也可以写成小写）
变音        #（升）  b（降）  n（还原）    可选，不写就是调号里的音
八度        数字，可选
```

八度以**中央 C = C4** 为准（MIDI 60）：

```
C3   低八度
C4   中央 C
C5   高八度
A4   标准音 a¹，440 Hz
```

**八度可以省略**——省略时自动沿用前一个音的八度。所以 `C4 D E F` 四个音都在第 4 八度。

## 时值

以**四分音符为 1** 个单位，写在冒号后面：

| 写法 | 时值 | 含义 |
|---|---|---|
| `:4` | 4 | 全音符 |
| `:2` | 2 | 二分音符 |
| `:1` 或省略 | 1 | 四分音符 |
| `:0.5` | 0.5 | 八分音符 |
| `:0.25` | 0.25 | 十六分音符 |
| `:3` | 3 | 附点二分 |
| `:1.5` | 1.5 | 附点四分 |

## 休止与小节线

```
R:2        二分休止
R:1        四分休止（也可只写 R）
|          小节线
```

## 举例

```js
cf: 'C5:4 | D5:4 | E5:4 | F5:4 | G5:4 | F5:4 | E5:4 | D5:4 | C5:4'
cp: 'C4:4 | B3:4 | C4:4 | D4:4 | E4:4 | F4:4 | C4:4 | B3:4 | C4:4'
```

第一类是 9 小节的全音符对全音符；第二类把 `:4` 拆成两个 `:2`：

```js
cp: 'C4:2 A3:2 | B3:2 D4:2 | C4:2 E4:2 | ...'
```

## 变音记号的延续规则（容易踩的坑）

**同一小节内，变音记号会延续到同音名、同八度的后续音**——这和五线谱上的规矩一致。

```js
'F#4 F4'      // 第二个 F 仍然是 F#，因为升号在本小节内有效
'F#4 Fn4'     // 写 n 才是还原，第二个音是 F 还原
```

跨小节自动清零：

```js
'F#4 | F4'    // 第二个 F 是 F 还原
```

检查器渲染音程时会正确处理这个规则，所以放心按五线谱的习惯写。

## 音程怎么判

检查器**不只看半音数**，而是同时用「音名级数」和「半音数」定性质。
所以下面两个音程虽然半音数相同，判定结果不同：

```
B3 – D#4     大三度    协和
B3 – Eb4     减四度    不协和
```

这一点在严格对位里很重要——记谱写法会影响协和判定，不是只看听起来像什么。

## 演奏练习音频

练习区的音频播放用的是同一套记谱，但额外支持和弦：

```
C4:1 E4:1 G4:1          三个音依次
<C4 E4 G4>:2            三个音同时，持续 2 拍
<C4 E4 G4>:2 R:2 |     和弦 + 休止 + 小节线
```

## 音域参考

同向播放时用到的标准声部音域（检查器的 `M05` 规则按这个判）：

| 声部 | 音域 |
|---|---|
| 女高音 soprano | C4 – A5 |
| 女低音 alto | G3 – F5 |
| 男高音 tenor | C3 – A4 |
| 男低音 bass | E2 – D4 |
